## 故事背景

### 戰後的安塞隆

《黑暗之后》是 SSI 克萊恩三部曲的終章，舞台位於《龍槍》的克萊恩世界。
前兩作《克萊恩英豪》與《幽靈騎士》的英雄，已在安塞隆對抗龍人與死亡騎士。
長槍之役留下的創傷尚未平復，效忠黑暗之后塔克西絲的勢力仍在各地活動。

隊伍的事蹟傳到帕蘭薩斯，羅拉娜將軍寄來一封信。她感謝英雄挫敗索斯王與姬蒂拉的陰謀，
讓世界擺脫他們的黑暗影響。她原想以隆重的慶典迎接英雄，如今卻有更緊迫的事，
要求隊伍儘速前來。將軍的部隊仍在搜尋大陸各處，尋找黑暗之后的追隨者。

### 凱爾高斯的災難

在帕蘭薩斯與羅拉娜會面後，隊伍前往凱爾高斯。這座城市已遭到摧毀，
許多居民死亡或失蹤。廢墟中留下巨龍與龍人的蹤跡，倖存者的遭遇讓英雄看見戰火再次逼近。
調查從城中的殘垣與港口開始，敵人的去向逐漸指向海上。

隊伍在港口遇見戴諾船長。他的妹妹克萊西亞也在襲擊後失蹤；為了追查龍人並尋找妹妹，
他願意載英雄出海。隊伍搭乘銀鯊號展開追擊，沿途的船骸、洞穴與人質，
把這場地方災難連向更大的陰謀。

### 海另一端的戰爭

冒險將離開熟悉的安塞隆，前往克萊恩另一塊大陸泰勒達斯。
黑暗之后正在當地培植新的軍隊，隊伍必須尋找盟友，阻止這股力量壯大。
旅程從海底延伸到陌生的城鎮、森林與敵方據點，最後通往火焰塔。
英雄面對的任務，是阻止塔克西絲再次進入物質世界，將戰火帶回克萊恩。

故事依《冒險手冊》「故事開始」及原版攻略書的導言、帕蘭薩斯、凱爾高斯與龍人洞穴章節整理；
跨海舞台與火焰塔亦見[遊戲官方介紹](https://store.steampowered.com/app/1904622/The_Dark_Queen_of_Krynn/)。
[攻略書原文](https://dlsaga.com/wp-content/uploads/2022/11/ks_darkqueen_cluebook_pdf.pdf)為 SSI 原版出版品，
譯名沿用本專案與前作術語，手冊來源及頁序見[手冊基線](docs/re/001-input-baseline.md#中文來源)。

## 遊戲機制

本作採用進階龍與地下城規則，核心循環是組隊、探索與取得線索、戰鬥、整備，再繼續旅行。
以下介紹原版設計；本專案接入及驗證範圍見「目前狀態」。

### 隊伍、職業與成長

玩家最多建立六名隊員，也可沿用《幽靈騎士》的角色繼續冒險。
種族、職業、陣營及六項能力值，決定角色能使用的裝備、法術與特殊能力。
七個可選種族包含人類、半精靈、坎德人、兩支矮人與兩支精靈；
非人類的複合職業可同時獲得多種能力，經驗則分給各職業，成長較慢。

| 職業 | 隊伍中的主要工作 |
|---|---|
| 戰士 | 穿戴重甲、承擔前線並使用多種武器 |
| 索蘭尼克騎士 | 近戰與領導，分皇冠、聖劍、玫瑰騎士團 |
| 聖騎士 | 近戰、治療與對抗邪惡，高等級可施法 |
| 遊俠 | 對抗巨人類，高等級可使用部分法術 |
| 牧師 | 治療、保護、超渡不死生物，能力亦受信仰神祇影響 |
| 魔法師 | 攻擊、控制與防護，從魔法書準備法術 |
| 賊 | 開鎖、解除陷阱與戰鬥背刺 |

戰鬥與任務會帶來經驗。達到門檻後，還要到訓練所接受訓練才能升級。
隊伍需要兼顧前線、治療、魔法與探索技能；角色名單順序也會影響開戰時的站位。

### 探索、對話與手札

城鎮與地下區域以第一人稱視角探索，區域圖協助辨認道路、房間與走過的位置。
玩家在酒館蒐集消息、與人物交談、調查環境，並透過選項決定接下來的行動。
有些遭遇需要交涉、解謎或救援，線索可能跨越多個地點。

原版會要求玩家查閱指定編號的旅行手札，補充信件、對話與圖像線索。
本專案已內建繁中手札與說明面板，可在遊戲中閱讀，再返回原畫面；另製作手動查閱的攻略頁。
攻略正文重新排版，地圖重新繪製並標註繁中，掃描只用於校對。

### 方格戰場與回合決策

進入戰鬥後，畫面切換至俯視戰術地圖。隊員依先攻順序行動，每回合重新決定順序，
可移動、近戰、遠射、施法、使用物品或守衛。負重與護甲影響移動，
牆壁、樹木、門口及隊友位置會影響接敵與部署。

射手被敵人貼身時不能正常遠射；賊可配合隊友牽制，繞到敵人背後背刺。
施法者在準備法術時受到攻擊，可能失去該法術。撤離相鄰敵人時也可能遭到追加攻擊。
因此，保護施法者、封鎖通道與集中攻擊，和武器傷害同樣重要。

| 畫面數值 | 閱讀方式 |
|---|---|
| 生命力（HP） | 可承受的傷害；倒下後須注意昏迷、垂死與包紮 |
| 防護力（AC） | 數值愈低，通常愈難被擊中 |
| 攻擊命中率（THAC0） | 擊中 AC 為 0 的目標所需擲值，數值愈低通常愈好 |
| 閃避率（Saving Throw） | 抵抗法術、毒物等效果的檢定，成功可減輕或避開效果 |

部分怪物具有特殊抗性，普通武器或某類法術可能無效。
戰後還要處理傷員、戰利品與法術消耗；全隊敗北時，必須讀取先前存檔。

### 法術記憶、休息與月相

法術需要先記憶，施放後再透過休息補回。魔法師只能準備魔法書中的法術，
可在訓練時學習，或從合適的卷軸抄錄；牧師則從所能使用的法術中選擇。
卷軸與魔法杖可直接作為物品使用，但有職業、辨讀或次數限制。
選擇幾次治療、幾次範圍攻擊，以及何時返回安全地點休息，是旅行中的資源管理。

克萊恩的三個月亮也影響魔法。白、紅、黑月分別對應不同法袍的魔法師，
月相會改變可用法術及施法能力；牧師信仰的神祇則提供不同的能力與額外法術。
同樣一支隊伍，在不同準備與時間條件下，可能適合不同的戰術。

### 裝備、箭矢與城內服務

背包中的裝備必須備妥才會發揮作用。武器、防具與魔法物品受職業限制，
魔法加值可能改善命中、傷害或防護；帶有詛咒的物品則可能需要解除詛咒才能卸下。
箭矢與弩箭另有數量、單支與整堆名稱，以及魔法加值，分半與集合都會改變清單顯示。

商店提供買賣與鑑定，神殿提供療傷服務，旅店方便整備與休息，訓練所負責升級。
出發前應檢查彈藥、負重、傷勢與記憶法術，並保留可回退的存檔。

機制依《冒險手冊》「人物與隊伍」「戰鬥」「魔法」「魔法寶物」及操作手冊整理，
來源與校讀限制見[手冊基線](docs/re/001-input-baseline.md)。
跨作角色匯入是原版功能，本專案尚未完成跨作匯入驗收。

### 原譜音樂

音樂保留原版 Roland 樂譜的音符、節奏與曲式，以取樣樂器重新合成，共8段。
開始、停止與音量跟隨原版命令，音樂開關獨立於語言、HD畫面與視窗大小。
樂器按角色對應，部分鐘聲與打擊音色採近似；這批音樂已通過樂譜及技術檢查，尚未完成聽驗。

本機整合版使用48kHz立體聲Ogg。音樂素材留在本機，不隨儲存庫提供；
缺少素材或音訊裝置時，工具列顯示「無音訊」，遊戲仍可操作。
來源、重建方法與驗證界線見[原譜音樂規格](docs/spec/006-hd-music.md)。

## 原版與 HD 圖庫

HD 保留原版配色、構圖及前景範圍。人物沿細緻油畫方向，怪物沿細緻奇幻方向製作。
HD 開關與視窗大小獨立，2 倍、3 倍及自由縮放都可使用。
下圖是已編譯素材的對照圖，不是遊戲執行截圖。

![已編譯戰鬥圖格的原版與 HD 總覽，每格左為原版、右為 HD](docs/images/combat-sprites-hd.png)

戰鬥圖格包含一般與攻擊姿態，不能把每格當作一種怪物。
已有素材會在來源及遮擋條件匹配時使用；未完成或未匹配的圖像維持原版。
本機圖文版列出現行主題全部項目、來源鍵及生成輪次，完整範圍見[HD 規格](docs/spec/004-hd-layer.md)。

## 如何啟動

開發與驗證入口使用 Linux、Docker 與可存取的 X11 桌面。建置、測試及開發中的遊戲程序均在容器中執行。
本機正式交付位於 `dist-all/v.1.0.2-20261029/`，包含以下產物，不隨Git提供下載：

| 位置 | 內容 |
|---|---|
| `full-local/` | Windows x86_64、Linux x86_64、macOS universal 三個完整版ZIP，含本機原版與衍生素材 |
| `patch/` | 同三平台的引擎包及本機資料匯入工具，不含遊戲資料、翻譯全文、HD與音樂 |
| `promo/` | 86秒故事與玩法篇：以遊戲封面開場，介紹故事、組隊、探索、戰術戰鬥及中文／HD功能；附字幕、分幕來源與影音檢查 |
| `smoke/`、`SHA256SUMS.json` | 封包啟動、獨立全螢幕地圖與返回檢查、交付雜湊清單；既有兩輪繪圖證據見CONTEXT |

完整版解壓後，Windows使用「啟動.bat」、Linux使用「啟動.sh」、macOS開啟「黑暗之后.app」。
存檔放在各平台的使用者資料目錄，位置見包內說明。引擎包只接受本機已準備的完整資料；
原版ZIP本身不包含本專案譯文與HD，不能直接當作完整中文資料匯入。

Linux已有容器內的原生啟動驗收，Windows已有Wine啟動驗收，仍未等同Windows實機。
macOS包含Intel與Apple Silicon兩種架構，尚未簽章、公證或真機驗收。
交付範圍見[收尾規格](docs/spec/007-completion-delivery.md)。

若本機合法原版、既有資料批與已建置的整合程式齊備，在專案根目錄執行：

```sh
bash tools/player.sh run
```

桌面音訊容器尚未建立時，先執行 `bash tools/player-audio-image.sh`。
啟動器會連接目前使用者的桌面音訊服務；無服務時嘗試可用的音效裝置。

需要重新準備與建置時，沿用本專案既有工具鏈與資料來源：

首次缺少Go音樂解碼依賴時，執行 `bash tools/music-hd.sh deps`。
音樂重建與安裝另見[原譜研究入口](docs/re/008-original-music.md#重建入口)。

```sh
bash tools/player.sh prepare
bash tools/player.sh build
bash tools/player.sh run
```

預設工作目錄為 `workplace/probe/player-current/`。原版來源唯讀，遊戲存檔、截圖及偏好分別放在：

| 資料 | 位置 |
|---|---|
| 遊戲存檔 | `workplace/probe/player-current/session/saves/` |
| 截圖 | `workplace/probe/player-current/session/screenshots/` |
| 視窗、HD 與音樂偏好 | `workplace/probe/player-current/session/preferences.json` |

入口與資料依賴見 [player.sh](tools/player.sh)及[整合規格](docs/spec/003-player-toolbar.md)。
全螢幕及各平台實機支援仍須各自驗證。

### 重建本機圖文版

合法原版及本機研究素材齊備時，執行：

```sh
bash tools/readme-gallery.sh readme-gallery-my-preview
```

輸出為 `workplace/probe/readme-gallery-my-preview/README.html` 及同目錄 `README.md`。
每次使用新名稱，保留舊展示與來源記錄。
本頁展示圖保存於 `docs/images/`。本機圖文版另列完整素材查閱表，`preview-index.json` 記錄來源、雜湊及展示界線。
重建只整理圖片與文件，不啟動遊戲，也不生成新的 HD 美術。
