## 長頁與查閱控制原型

維持 DRAFT。依前作規格 007 的 F5、PgUp／PgDn、左右方向鍵與 Esc，建立可撤回的查閱原型。
F5 翻閱原版已實際引用過的手札，左右鍵只走已記錄的編號；不把畫面測試的手札加入已讀清單。
本批只做程序內紀錄，不先新增跨次啟動的檔案或變更原版存檔。

- 載入 64 則有正文的校讀稿；12／25／64 保持圖文待接入，13 不補造。
- 每頁仍為一行標題、十三行正文、一行頁碼。每則最多三頁，超出拒絕，不裁文。
  分頁保留完整字序、空行與禁則斷行；頁碼及操作提示從 TSV 取得。
- 自動顯示的原版 Return 照常送進遊戲，下一段入口撤除。翻頁鍵由前端消耗。
- 查閱模式暫停原版執行，關閉後從相同狀態續行。只在完整呈現交易之間開啟，避免停在半繪製狀態。
  正式按鍵與暫停體驗尚未定案，不從此原型升為正式契約。
- 畫面元件測試可在正常重播的穩定畫面暫停，逐頁顯示全部載入正文，或以真實鍵盤操作第 50 則長頁。
  此分支須另標元件預覽，不能偽造原版引用、寫入已讀清單，或當作 63 則新原版流程已通過。
- 主要驗證仍走八個正常宮殿動作，原文／繁中及控制組的原版暫存器、RAM、色號、按鍵與寫檔結果相同。
  另檢查完整正文逐頁覆蓋、實際 GPU 讀回、關閉恢復、前端按鍵未進原版佇列，以及既有單頁輸入相容。

2026-10-23 已通過全批 66 頁元件畫廊、未讀時的空清單、長頁往返與邊界、已讀清單及關閉後續行。
實際 X11 測試分為第 50 則長頁元件與第 54 則已讀查閱，兩側合計十八張視窗逐點對上 GPU 畫格。
每次閱讀操作及原版執行批次須先提交完整畫格，再接受下次 Update，避免補跑更新跳過操作結果。
新證據與重播入口見 [研究 004](../re/004-story-text.md#2026-10-23手札全批正文的分頁與已讀查閱原型)。
仍為 DRAFT；沒有把新 63 則稱為已走過原版引用流程，也沒有新增正式啟動器。

## 圖文重繪資料原型

維持 DRAFT，先建立第 25、64 則的可縮放重繪圖。第 25 則對照英文第 37 頁、中文第 99 頁，
第 64 則對照英文第 47 頁、中文第 127 頁。牆、門與拱門分別記錄，不把印刷格線座標當作遊戲地圖座標。
自動提取僅產生候選，文字與手寫註記的誤認、符號造成的斷線都經原圖校閱後另記補正。

- 私有 JSON 記錄整數方格邊、符號種類、原始圖像雜湊與校閱來源；版面座標另列，僅供原型。
  此格式不進正式存檔或執行路徑，正式圖文閱讀契約仍待前端原型與使用者定案。
- 名稱、圖例與標題沿既有校讀 TSV；程式只引用 key。重複房名保留每個位置，長名稱分行，不裁字。
- SVG 只輸出重建幾何與字型輪廓，不嵌入 PDF、掃描或原圖像素；PNG 僅作本機目視校驗。
  私有資料及輸出維持原版衍生內容的權利分類，不因重繪而加入 Git。
- 檢查方格邊唯一、符號位置、圖例一致、文字字序與字型覆蓋；以原圖、重繪圖與補正索引逐項回查。
  完成繪圖不等於正常遊戲引用、遊戲每格或正式閱讀入口驗收。
- 第 12 則仍保留破損信件的缺文。原圖碎片與七組文字另作校閱，不能把省略號串成一封完整信件。

工具入口為 [journal-diagrams.sh](../../tools/journal-diagrams.sh) 與
[journal_diagrams.py](../../tools/journal_diagrams.py)。執行
`bash tools/journal-diagrams.sh FORMAT GEOMETRY LAYOUT CATALOG OUTPUT`，`FORMAT` 為 `svg` 或 `png`，四個路徑均相對
`workplace/probe/`，輸出檔必須全新，父目錄須已存在。SVG 沿既有 FontTools 4.53.1 映像檢查字型覆蓋並輸出輪廓，
PNG 沿既有 Pillow 11.3.0 映像量測實際字墨與遮線；兩者均使用唯讀字型及容器內渲染。
研究資料及重繪證據集中於既有 `workplace/probe/pane-render-20261022/journal-diagrams-20261023/`。

2026-10-23 的兩圖原型共 955 條方格邊，含 145 扇門與 86 處拱門。21 個標籤均由原 TSV 取得，
重複房名與分行文字完整保留，字墨沒有遮線。SVG 在兩次獨立 Chromium 程序中繪製一致，沒有點陣圖元素或外部素材。
重建與十一項防護證據見 [研究 001](../re/001-input-baseline.md#2026-10-23兩張手札地圖的繁中向量原型)。
此處只完成印刷地圖的重繪原型，不擴張為三則圖文、遊戲引用或全冊閱讀完成。
