## 工具與私有資料

- `tools/ui_journal_reader.go`：載入、分頁、已讀查閱、生命週期與呈現。
- `tools/ui_list_paragraphs.go`：原版完整來源核對及開關接點。
- `tools/ui_list_inputs.py`：由正式詞條、實際引用與校讀稿建立隔離輸入。
- `tools/ui-list-live.sh prepare INPUT PARAGRAPH_TRACE BOOK_REVIEW [READER_UI]`：路徑依序相對
  `workplace/probe/`、同處、`workplace/translation/`、同處。輸入目錄必須全新。

  原有段落 TSV 不混入書籍正文；`font-zh-TW.tsv` 只供字模聯集重建。
- `tools/ui_list_live_check.py`：從原版觀測獨立重建開關，驗完整正文、斷行、每幀像素與原版狀態。
- `tools/ui_journal_reader_check.py`：手札生命週期、獨立禁則排版與像素合成的檢查模組。
- `tools/x11_menu_driver.c`：既有選單驗證器增加 `reader-long`、`reader-seen`，只送 X11 鍵盤事件及擷取視窗。
  `ui-list-live.sh keys-en|keys-zh STATE REQUEST INPUT RESULT false PROBE MODE` 以容器自有 Xvfb 執行，
  `MODE` 為上述兩種；長頁以明列的元件預覽開啟，已讀測試以控制重播開啟，關閉與翻閱使用實際鍵盤。

## 驗收與停止線

正常宮殿按鍵從引用前到告別及返回城市，核對來源在首字元前取得，閱讀框完整顯示、原版提示保留、
下段撤除且恢復背景。原文／繁中八個動作狀態及原版控制組一致。
引用繪製與退出入口以最多 2,000 道指令細分取樣；只對實際區間作同幀結論。
錯編號、缺頁、超頁及未知下一段應各有防護證據。沒有全冊或正式接入完成聲明。

2026-10-23 的隔離原型完成上述單頁抽樣。開啟／下一段入口及實際恢復分兩批驗證，
原文／繁中各 3,986、998 幀，細驗共 8M 道指令。缺頁與未知下一段各 500 組，十四項防護通過。
證據入口為 [研究 004](../re/004-story-text.md#2026-10-23手札-54-的單頁閱讀原型)，
本規格維持 DRAFT，沒有升為正式玩家入口。

## 校讀稿擴充的容量邊界

本批已新增 63 則正文稿，加上 54 共 64 則；67 個原編號標題完整，仍沒有 13。
兩張地圖有 21 個標籤，第 12 則有七組片段文字，三則圖文仍未重建。
來源、格式、術語及字模證據見 [研究 001](../re/001-input-baseline.md#2026-10-23手札正文校讀稿與字模量測)。

量測沿目前 38 字格及 16px 行高，47、50 分別有 14、16 行，超出單頁的十三行容量。
其餘 62 則單頁容量足夠，尚不等於 62 則已在原版引用路徑驗證。
不直接把含三則缺正文圖文的整份稿件交給現行單頁載入器。
分頁、手動查閱及圖文接入仍須補齊規格與正常路徑證據，不能以離線排版圖替代。

## 長頁與查閱控制原型

維持 DRAFT。依前作規格 007 的 F5、PgUp／PgDn、左右方向鍵與 Esc，建立可撤回的查閱原型。
F5 翻閱原版已實際引用過的手札，左右鍵只走已記錄的編號；不把畫面測試的手札加入已讀清單。
本批只做程序內紀錄，不先新增跨次啟動的檔案或變更原版存檔。

- 載入 64 則有正文的校讀稿；12／25／64 保持圖文待接入，13 不補造。
- 每頁仍為一行標題、十三行正文、一行頁碼。每則最多三頁，超出拒絕，不裁文。
  分頁保留完整字序、空行與禁則斷行；頁碼及操作提示從 TSV 取得。
- 自動顯示的原版 Return 照常送進遊戲，下一段入口撤除。翻頁鍵由前端消耗。
- 查閱模式暫停原版執行，關閉後從相同狀態續行。只在完整呈現交易之間開啟，避免停在半繪製狀態。
  正式按鍵與暫停體驗尚未定案，不從此原型升為正式契約。
- 畫面元件測試可在正常重播的穩定畫面暫停，逐頁顯示全部載入正文，或以真實鍵盤操作第 50 則長頁。
  此分支須另標元件預覽，不能偽造原版引用、寫入已讀清單，或當作 63 則新原版流程已通過。
- 主要驗證仍走八個正常宮殿動作，原文／繁中及控制組的原版暫存器、RAM、色號、按鍵與寫檔結果相同。
  另檢查完整正文逐頁覆蓋、實際 GPU 讀回、關閉恢復、前端按鍵未進原版佇列，以及既有單頁輸入相容。

2026-10-23 已通過全批 66 頁元件畫廊、未讀時的空清單、長頁往返與邊界、已讀清單及關閉後續行。
實際 X11 測試分為第 50 則長頁元件與第 54 則已讀查閱，兩側合計十八張視窗逐點對上 GPU 畫格。
每次閱讀操作及原版執行批次須先提交完整畫格，再接受下次 Update，避免補跑更新跳過操作結果。
新證據與重播入口見 [研究 004](../re/004-story-text.md#2026-10-23手札全批正文的分頁與已讀查閱原型)。
仍為 DRAFT；沒有把新 63 則稱為已走過原版引用流程，也沒有新增正式啟動器。
