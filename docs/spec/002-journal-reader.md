## 呈現契約

| 項目 | 原型契約 |
|---|---|
| 辨識 | 完整來源雜湊、專屬 `26B4:3320`、色彩、清除旗標、安全框共同匹配；編號另與正式英文模板核對 |
| 觸發 | 已接受段落的 `JournalEntry` 有校讀正文才開啟；缺正文保留引用文字，記錄 unavailable |
| 原文 | 正式 `ui.aa93370ee0689e9a462e` 模板及實際參數衍生，譯文不參與原版判斷 |
| 輸出框 | 640×400 的 `[16,624)×[16,256)`，黑底、黃標題、白正文，沿原版色盤；保留左上 `[16,32)×[16,32)` 徽章角，標題從 x=32 起 |
| 排版 | 正文每行最多 38 字格，標題 37 格，16px 行高；標題一行、正文最多十三行，保留段落空行；超長拒絕，不截文 |
| 字型 | 前作 `font/jf-openhuninn-2.1.ttf`，來源與授權沿既有字型契約；字模下方四列須無字墨 |
| 同幀 | 閱讀框加入既有完整畫面合成，再選擇保留上一完整畫格；不在保留畫格後另畫新狀態 |
| 關閉 | 下一個 `0B72:0311` 入口先撤除，即使新段落無法辨識；原版 Return 及 CPU 照常運行 |
| 隔離 | 不寫原版 RAM、色號緩衝、存檔、亂數或按鍵佇列；像素改動只在已核定呈現框 |

## 工具與私有資料

- `tools/ui_journal_reader.go`：載入、單頁排版、生命週期與呈現。
- `tools/ui_list_paragraphs.go`：原版完整來源核對及開關接點。
- `tools/ui_list_inputs.py`：由正式詞條、實際引用與校讀稿建立隔離輸入。
- `tools/ui-list-live.sh prepare INPUT PARAGRAPH_TRACE BOOK_REVIEW`：三個路徑分別相對
  `workplace/probe/`、同處、`workplace/translation/`。輸入目錄必須全新。
- `reader-ui-review.tsv` 保存自有介面文案；校讀稿合併為私有 `reader.zh-TW.tsv`。
  原有段落 TSV 不混入書籍正文；`font-zh-TW.tsv` 只供字模聯集重建。
- `tools/ui_list_live_check.py`：從原版觀測獨立重建開關，驗完整正文、斷行、每幀像素與原版狀態。
- `tools/ui_journal_reader_check.py`：手札生命週期、獨立禁則排版與像素合成的檢查模組。

## 驗收與停止線

正常宮殿按鍵從引用前到告別及返回城市，核對來源在首字元前取得，閱讀框完整顯示、原版提示保留、
下段撤除且恢復背景。原文／繁中八個動作狀態及原版控制組一致。
引用繪製與退出入口以最多 2,000 道指令細分取樣；只對實際區間作同幀結論。
錯編號、缺頁、超頁及未知下一段應各有防護證據。沒有全冊或正式接入完成聲明。
