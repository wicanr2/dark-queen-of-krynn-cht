## 素材契約

每份主題有獨立 `hd.json`，版本1、資產密度3、`Ready` 及 `Assets`。
資產密度是內部貼圖尺寸，與視窗倍率分開。
每項包含 `Key`、原版RGBA PNG、HD PNG及各自SHA-256。完整主題先載入，任一項缺少、
損毀、尺寸或遮罩失配時整組回退原版，不啟用半份主題。

原版寬高為W、H，HD固定為3W、3H。HD的alpha必須等於原版前景遮罩的三倍展開；
透明戰鬥角色不擴大佔地，不清掉未知背景，不以附近地板猜補背景。
生成圖作為材質與細節來源，依原版前景範圍編譯，原始生成PNG另存，不能把原版放大稱作HD。
純色、過短邊緣及不足以辨識的零碎圖像保留原版，不當成獨立角色重繪。

資產編譯入口為 [hd_assets.py](../../tools/hd_assets.py)，在既有 Pillow Docker 內執行。
`add` 讀來源索引、原版PNG及內建imagegen原圖，保存master、三倍前景與逐項雜湊；
`--round`只接受1或2，第二輪後不允許同項第三輪覆寫。
`accept`需要已確認的風格記錄，否則主題保持未就緒，不以背景作業逾時或沉默當作授權。

## 接入

[player_hd.go](../../tools/player_hd.go)只加入一般玩家建置，由可選載入器接到既有呈現層。
舊研究工具無須可選主題，亦不改固定 dosgolem 來源。

- 來源命令在原版第一個影像像素前取得，使用原始標頭及內容雜湊辨識資產，不再全畫面搜尋原圖。
- 畫格整理只核可見頁命令指定位置的原版不透明色號，不讀回中文畫面作判斷；隱藏頁命令等原版翻頁後再核。
- 色號、可見頁與色盤不變時重用匹配結果，繪製順序沿原始來源命令。色盤改變暫留原版，不刪除有效命令。
- 中文詞框、劇情與閱讀框列為保護區。與保護區相交的圖像回退原版，避免蓋住文字或閱讀面板。
- 原子呈現仍保留前一完整畫格；保留期間重用上一個完整HD結果，不對半繪製的原版畫面重新找圖。
- 倍率、原版檢視與HD開關切換時撤掉過期比對快取，不將上個場景的HD蓋到新畫面。
- 玩家呈現畫布固定960×600，HD依原版座標貼圖；文字及已定稿工具列維持原有邏輯比例。
- 視窗可為640×400、960×600或自由調整大小，僅縮放完整合成畫面。HD開關及視窗倍率各自保存。
- 原版檢視暫時顯示原始畫面，HD偏好保持；切回中文後恢復先前選擇。遊戲資料、亂數、存檔及原始畫面緩衝保持。
- 工具列HD格位固定80個既有邏輯像素，載入後只改狀態文字與顏色，不移動後方項目。
- 截圖只在玩家要求時讀回當下合成畫面，包含HD與中文，不逐幀寫檔。
- 中文、HD在私有後緩衝完成後交換前緩衝，視窗只繪完整前緩衝；交易未完成時保留上一張完整畫面。

這個契約以完整可見來源為界。被遮住、循環色盤、未解動畫、尚未重繪或沒有完整匹配的圖像，
保留原版；不將這些回退說成全畫面HD已完成。
