## 入口與資料

[player.sh](../../tools/player.sh) 提供 `prepare`、`build`、`run`，預設整合目錄為
`workplace/probe/player-current/`。資料準備由
[player_inputs.py](../../tools/player_inputs.py) 複製不可變來源，另產工具列字模與雜湊清單。
不載入研究快照或原版按鍵重播，不放入預設隊伍、測試狀態或答案。

```sh
bash tools/player.sh prepare
bash tools/player.sh build
bash tools/player.sh run
```

目前入口可直接啟動已建置的 `player-current`：

```sh
bash tools/player.sh run
```

`run` 需要目前桌面的 `DISPLAY`、既有 X11 存取權及合法原版。所有程式在離線 Docker 內執行。
原版目錄唯讀，存檔使用同批 `session/saves/`，截圖放 `session/screenshots/`，
前端視窗倍率與 HD 偏好分別放 `session/preferences.json` 的 `Scale`、`HD`。不覆寫原版來源存檔或研究主線快照。
工具列選擇不寫入 DOS 存檔，也不影響亂數、條件比較或遊戲資料識別。

呈現畫布固定為 960×600，中文及工具列維持原有 640×400 邏輯比例。
2 倍與 3 倍只改視窗尺寸為 640×400 與 960×600，視窗也可自由調整大小。
HD 開關獨立，縮放不會自動啟用或停用 HD。正常入口不逐幀寫圖、不保存完整研究收據。
主機端埠操作及呈現事件歷程有界保留，原始遊戲狀態及 VGA 現況保持。

## 示範中斷與返回

已證實：主選單以D選取示範，播放中按Esc返回主選單，再以P進入角色管理。
這沿用原版中斷處理，不跳轉IP、不改寫原版記憶體、不自行重建主選單。
前端將Esc送入原版鍵盤路徑；原生遊戲繼續處理畫面、輸入與狀態。
片頭空白鍵略過與示範Esc返回分開，不將空白鍵改成全遊戲的Esc別名。

代表抽驗為`player-sample-demo-20261028-r2/`：967e2445正常冷啟動後選示範，
森林示範畫面可見，Esc返回與原主選單相同，再進角色管理十二鈕。
既有縮放、語言及說明返回的五張基準差異0，guest寫入0，正常關窗完成。
不外推全部示範段落或新冒險。可重現入口為：

```sh
bash tools/player-sample.sh player-sample-demo-新的名稱 player-current demo
```

首版探針的Esc返回已通過，但額外假設空白鍵也能中斷示範未通過；保留在
`player-demo-20261028/`，只作該假設的診斷，不當作成功收據。
