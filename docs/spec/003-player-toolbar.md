## 目前契約

使用者於 2026-10-25 指定先完成中文化、再補 HD，取消後續遊戲抽驗，並明確要求工具列。
本規格整理可持續接受一般鍵盤的整合開發入口，不把取消抽驗寫成已完成新增驗收。
角色管理沿已確認的 20 像素圓體，其他畫面暫保留既有 16 像素原型；正式字級、閱讀版面、
HD 風格／倍率仍依既有選項待定。DRAFT 入口不冒稱正式版或全遊戲中文化完成。

## 入口與資料

[player.sh](../../tools/player.sh) 提供 `prepare`、`build`、`run`，預設整合目錄為
`workplace/probe/player-integration-20261025/`。資料準備由
[player_inputs.py](../../tools/player_inputs.py) 複製不可變來源，另產工具列字模與雜湊清單。
不載入研究快照或原版按鍵重播，不放入預設隊伍、測試狀態或答案。

```sh
bash tools/player.sh prepare
bash tools/player.sh build
bash tools/player.sh run
```

目前本機已建置的批次為 `player-integration-20261025-r3`，可明確指定該名稱啟動：

```sh
bash tools/player.sh run player-integration-20261025-r3
```

`run` 需要目前桌面的 `DISPLAY`、既有 X11 存取權及合法原版。所有程式在離線 Docker 內執行。
原版目錄唯讀，存檔使用同批 `session/saves/`，截圖放 `session/screenshots/`，
前端倍率偏好放 `session/preferences.json`。不覆寫原版來源存檔或研究主線快照。
工具列選擇不寫入 DOS 存檔，也不影響亂數、條件比較或遊戲資料識別。

目前畫布維持 640×400。2 倍與 3 倍只改視窗尺寸為 640×400 與 960×600，
不代表已有 HD；視窗可調整大小並保留比例。正常入口不逐幀寫圖、不保存完整研究收據。
主機端埠操作及呈現事件歷程有界保留，原始遊戲狀態及 VGA 現況保持。

## 工具列開發樣式

工具列預設隱藏，游標移至畫布頂端六個像素內時顯示，離開頂端二十四像素範圍後隱藏。
項目依實際中文字數量測，集中使用同一動作處理函式；獨立文案來源為
[toolbar.zh-TW.tsv](../../text/toolbar.zh-TW.tsv)。工具列不縮放或重排原版選單。

| 項目 | 行為 | 狀態 |
|---|---|---|
| 2 倍／3 倍 | 調整顯示視窗；F2 切換 | 已接動作，未新增 GUI 抽驗 |
| 繁中／原版 | 切換呈現覆層；F12，遊戲狀態保持 | 已接動作，未新增切換抽驗 |
| HD | 素材尚未接入時顯示「HD待補」，按下顯示原因 | 停用，不能當作 HD 完成 |
| 手札 | 共用已讀手札查閱及 F5 控制 | 已接既有閱讀動作，原版顯示時停用 |
| 說明 | 共用兩冊說明及 F6 控制 | 已接既有閱讀動作，原版顯示時停用 |
| 攻略 | 正文及重繪地圖接妥後才能啟用 | 停用並說明原因，不嵌 PDF |
| 截圖 | 儲存目前遊戲呈現畫格；F10 | 已接動作，不改原版輸入 |
| 全螢幕 | 開關全螢幕；F11 | 已接動作，平台實機未驗 |

滑鼠在工具列的按下與放開由前端處理，不能成為原版操作。
F5、F6 與閱讀中的翻頁、關閉沿既有閱讀元件，不向原版送出相同按鍵。
視窗關閉只結束目前程序，不自動代替玩家儲存 DOS 遊戲。
