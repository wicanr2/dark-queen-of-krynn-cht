## 使用者澄清：相同內容只繪製一次

使用者補充，完整接管同時要求避免原版與 HD 的重複繪製成本。
澄清前的程式執行原版繪圖，再由 `ScreenRGB` 取得背景影像並合成中文／HD，沒有跳過原版繪圖。
完整前緩衝只能控制提交邊界，尚未達成本節目標。下方 READY 各節是現有過渡實作的契約，
不能據此宣稱單次繪製或已消除重複光柵化。

目標已由使用者確認。候選已接來源命令、所有權與迴圈跳轉，機器效果及虛擬時間尚未完成對照，維持 DRAFT。

- 已接管命令：在原版像素生成／搬移迴圈前辨識，直接交自有繪圖層，跳過對應原版繪圖。
- 未接管命令：只執行原版路徑，不再為同一內容追加 HD 繪製；覆蓋範圍須明列。
- 中文、HD、原版美術選項共用命令路由，選定一種實際繪製方式；視窗大小仍獨立。
- 必要的資源識別、邏輯副作用、返回值及暫存器／旗標契約須保留；未知之處先查證，不猜返回狀態。
- 若遊戲讀回顯存，先追查讀寫端並定義最小相容資料；不以完整原版背景光柵化維持所有覆繪判斷。
- 完成判準須包含命令級計數：已接管內容的原版繪製為零，自有繪製一次；
  不能只以視窗沒有閃爍或截圖相同當作通過，也不在未量測前宣稱效能剛好快兩倍。
- 沿使用者要求不追加遊戲抽驗；必要反組譯、建置及命令路由檢查不能冒充已完成全路徑驗收。

位址及控制流有靜態證據；替換後的完整 CPU、RAM、堆疊及時間效果尚未達 READY。
以下只描述已寫出的候選範圍，不宣稱未知格式、裁切與所有繪圖入口均已完成。

- 完整且未裁切、X 對齊四像素的 10h／15h 圖像，保留 `sub_26BB4` 的位置計算及最後平面設定，
  跳過四個平面的像素迴圈，再執行原 epilogue。只接受來自 `sub_2717A` 的已列呼叫。
- 12h 壓縮圖像限定 Mode 0Fh、寬度可整除八且無裁切。保留原準備程式，跳過解壓及逐列寫入，
  執行最後一列的位置計算、平面三設定及原 epilogue。原列迴圈的 Y 遞增導出最後列為 `Y+H-1`。
- `sub_12EE1` 的八乘八字形由原位元組及前後景色號建立命令。跳過八列像素迴圈，
  執行原最後平面設定及列尾、還原與返回，保留最後的 AX／CX／DX 與計算旗標。
- `sub_110B8` 及同色雙位元組的 `sub_110EB` 純色塊保留原準備與最後列尾，跳過逐像素／列迴圈。
  僅接四平面八位元寫入、完整列距及可表示的畫面範圍。
- 接管要求 GC mode 40h、BitMask FFh、Enable Set/Reset 0、Rotate 0、DF 0，以及已知的原版資料段。
  其他情況只走原版，不追加 HD；不猜未證實的混色或遮罩行為。
- 自有場景保存原生色號、透明範圍、來源與目的頁。顯存讀回時才補該位址的相容資料；
  文字生命週期需要的色號視圖使用增量快取，不能先產生整張原版 RGB 當作 HD 底圖。
- 自有圖像、原版美術預覽及 HD 由同一場景選一種貼圖。被接管的像素在背景底圖挖空，
  字形／圖像不得先畫原版再覆 HD；裁切與文字保護只改單次輸出的遮罩。
- 舊 UI 的頁面及清除追蹤接收明列為 presentation 的邏輯寫入通知，不能把它們記成原版 CPU 寫入。
  光柵期間若已接管函式仍發出顯存寫入則立即停止，不以雙重繪製補洞。
- 純狀態、來源解碼、矩形輸出與建置只驗證呈現資料模型。它們不能證明跳過原迴圈的機器效果正確。
- 直接替換須保留已驗的虛擬指令成本及週期，不能跨過 IRQ、畫面回呼、輸入或執行配額邊界。

- 玩家畫面由本專案繪圖層統一提交，文字、HD 與工具列在私有緩衝完成後才顯示。
- 原版規則、亂數、資料識別及存檔保持；原版顯存可留作背景相容資料，不直接提交到視窗。

## READY：完整畫格提交

一般玩家入口採獨立的原版背景影像與前後兩張 960×600 呈現貼圖。
原版背景影像不直接畫到視窗，中文與 HD 在後緩衝完成後才交換前後緩衝。
視窗每幀只取已提交的完整前緩衝，工具列由前端另畫；截圖取該完整畫面。
原版預覽也循相同提交邊界，沒有把原生半成品直接送到視窗的例外。

[掛勾清單](005-render-hooks.json)記錄原版 EXE 雜湊、IDA 9.4 定位、檔案偏移、
resident 執行期位置及八個前置位元組。二十五個入口皆以原始 `retf` 為返回契約，
包括既有格式化印字入口，避免只保護個別字形的半成品。
型別標籤只用於診斷，不拿未證實的參數意義決定原版行為。

- 啟動前逐項核入口 bytes；失配停止啟動，不退回沒有保護的舊呈現路徑。
- 入口記錄呼叫者與 SS:SP，對應返回位置及 SS:SP+4 才關閉交易，支援巢狀與同址重入。
- 任一交易或既有文字／換頁交易未完成時，保留上一張完整前緩衝，不重新貼 HD。
- 原版資料、CPU、VGA、時間與返回值保持；此階段觀察繪圖，不跳過原版函式。
- 背景相容影像只在二十五個已列交易均完成時更新；相同背景可重新合成新的閱讀面板。
- 沒有新遊戲抽驗。驗證限建置、來源 bytes、manifest 與靜態配對契約，不宣稱全部繪圖入口已覆蓋。

實作入口為 [player_render_owner.go](../../tools/player_render_owner.go)，只加入一般玩家建置，
研究重播來源清單保持。未辨識的影像、動畫與部分裁切仍保留原版，不能宣稱全部命令已接管。

## READY：影像繪製前來源命令

`162E:229E` 在影像標頭取得後、第一個影像分派前，讀取八位元組標頭、`DX:AX` 內容位址，
以及 `SS:BP+6` 的 Y、`SS:BP+8` 的 X，扣除標頭的 Y／X 偏移後產生來源命令。
掛勾只讀取資料，原版執行順序與顯存保持。

[HD 呈現層](../../tools/player_hd.go)以來源標頭加內容的完整雜湊決定資產，
目的位置直接來自命令，移除原有全畫面像素搜尋。每項 HD 記錄原始區塊長度、SHA-256
及八位元組標頭，缺少來源記錄時整組主題不啟用。來源辨識早於原版圖像繪製。

- 只接原生 320×200 範圍內的完整影像；負座標或裁切超出範圍時保留原版。
- 每次完整畫格只核可見頁已攔截位置的原始色號，撤除被清除或遮擋的命令，不搜尋其他位置。
- HD 關閉與原版預覽仍整理來源命令，避免長時間累積；切換視窗與 HD 不清掉有效的場景命令。
- 中文及閱讀保護區保持，命令不畫進文字框。新素材未齊時沒有延後找圖補上的路徑。
- 影像身分及位置有靜態來源證據，新掛勾仍未實機走訪；沿使用者指示不追加抽驗。

## READY：完整短字串的來源命令

既有 `1212:03A0` 在首個字形前提供完整格式字串或 `%s` 的完整來源。
`13C7:0CB6` 是座標正規化後、第一個字形繪製前的位置，原字元仍在 `SS:BP+10`，
原生 Y／X 在 `SS:BP+6`、`SS:BP+8`。讀取完整來源與逐字位置，全部字元、位置及返回均吻合才接入。

新增來源詞表由正式繁中主表及原文表衍生，只取已翻譯的 UI／名稱。歧義、控制碼、格式符號、
超過八十個 ASCII 字元、缺字及字墨超過八列原生像素的來源保留原版。
不在共用字串查找端翻譯，不改語意判定，也不把 810 個未接的 ECL 片段直接倒進完整段落處理。

- 開始印字前取得來源；第一個字形繪製前取得實際位置，原位置必須在 320×200 範圍內。
- 只接印字前底色色號均勻的八像素高詞框，底色取目的頁的實際色號，不猜附近背景。
- 全部字形必須逐字相同、同一行且每字向右八像素；不把換行、捲動或非標準字形硬套短標籤。
- 譯文較寬時，以原左緣及 16px 字級計算所需詞框；包含右側延伸區的整框必須在印字前均為
  相同底色色號，且位於畫面內。印字完成後整框也須只有原字形前景及底色；其他原版寫入改變
  延伸區即撤除。不縮字、不移動原版按鈕、不覆蓋原有數字或其他已畫內容。
- 格式化印字返回後保存原版該詞框，後續改動就撤除；呈現時既有詞框、劇情與閱讀保護區優先。
- 字型維持 16px 圓體，字模新增獨立保存，既有 16px／角色 20px 字模及原十八份輸入保持。
- 所有短字串在私有後緩衝合成，原版印字交易未完成時不提交。資料可接入不等於新分支已走訪。
