# 全量串接、兩輪抽驗與正式交付

狀態：READY。2026-10-29使用者明確指定先完成串接，再抽驗兩輪，沒有問題即收尾、正式打包與錄製推廣影片；平台已選Windows、Linux、macOS。沿現況8c2d1a0，不重開已接受的HD圖稿。

## 串接與停止線

- 正式7730筆譯文逐項核對執行入口，完整段落的片段可由已接入PassageGroups承接；不能只比TSV鍵數就判漏接。對應記錄來源雜湊及組句輸出鍵。
- 尚未納入主譯表的679個候選單獨分類；存檔A至J、檔名、除錯及未知位元串維持原始識別，不把雜訊硬譯成玩家內容。
- 完整短字串、格式、段落與Go繪圖保留既有安全守衛。補上有界的未匹配診斷與實際原版像素寫入定位；新診斷不改CPU、記憶體、亂數、輸入或存檔。
- 原版控制流與必要索引相容資料維持；事件預算不足而改用Go細粒度命令不計成原版繪圖。已接管命令不允許原版先畫再疊中文或HD。
- 固定兩輪代表抽驗。第一輪核冷啟動、選單、閱讀與代表探索／戰鬥；第二輪核另一組固定來源、音樂／HD／語言切換、箭矢及存退讀的有效收據。正常入口與狀態注入分列。只修實際失敗，未走訪項保留證據界線，不再展開無限逐房或硬體研究。
- 兩輪成功即按使用者門檻完成；音樂技術檢查與實體聽感分列，不以等待額外聽驗重新阻擋已授權的本機交付。

## 封包與影片

- 三平台：Windows x86_64、Linux x86_64、macOS x86_64及arm64。實際建置及啟動能力逐項記錄；macOS未有真機時明列未驗，不把交叉編譯當真機通過。
- 初次正式版採`v.1.0.0-YYYYMMDD`，日期以Asia/Taipei的實際定版日決定。已有同名tag或目錄立即停止覆寫。程式、封包、manifest及tag採同一版號。
- 唯一交付根為`dist-all/<版本>/`，子目錄按知識庫交付契約。`full-local/`含本機合法來源與完整中文／HD／音樂，`patch/`只放權利已確認的引擎及匯入工具；所有完整素材、手冊全文及原版檔案維持本機。
- 使用者未授權公開Release或上傳影片。本輪先完成本機正式產物、內容清單、SHA-256、必要素材與啟動檢查。
- 推廣片錄製目前程式的實際畫面，展示中文、HD、閱讀與工具列；場景fixture另標記來源，不能冒稱正常全程通關。沿已授權的原譜HD音樂，明列取樣重製來源，不冒稱原版硬體錄音。影片及音樂只留本機。
- 影片驗codec、尺寸、fps、音量、非靜音、削波、黑幀、凍結及字幕邊界，保留分幕抽幀與權利資料。靜態閱讀畫面不誤判為程式凍結。
