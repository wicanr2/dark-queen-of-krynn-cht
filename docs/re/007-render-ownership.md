# 繪圖層接管與提交邊界

使用者要求完整接管繪圖，避免先顯示原圖或英文，再補 HD 與中文。
工作沿 [#7](https://github.com/wicanr2/dark-queen-of-krynn-cht/issues/7)，
原版規則及存檔保持，HD 與視窗大小獨立，不新增遊戲抽驗。

## 目前證據

- 已證實：目前一般入口的 `Draw` 先由 `ScreenRGB` 建立原版底圖，再處理中文，最後貼 HD。
  未知來源及完整圖像比對失敗時會保留原圖；這不是完整繪圖接管。
- 已證實：現有印字、填色、選單及換頁已具部分入口與返回事件，見[規格 001](../spec/001-early-text.md)。
- 未知：圖像解碼、貼圖、清除、捲動與換頁是否全部經過相同入口。需由本作 `.i64` 追查，不能沿用前作位址。

## 影像來源與交易邊界

以下定位來自 IDA 9.4 的 `render-functions.json`。resident 的換算沿既有已證實映射，
逐項另核 MZ 載入位置與 2,291 筆 relocation；掛勾前八個位元組不含 relocation。
主資料庫及原 EXE 保持唯讀。執行器、資料來源及本輪工具雜湊在本機 `static-evidence.json`。

| 原始定位 | IDA linear | 檔案偏移 | 執行期定位 | 靜態結論 |
|---|---|---|---|---|
| `sub_27580` | `0x27580` | `0x19980` | `162E:23A0` | 已證實：資源查找後呼叫完整影像繪製 |
| `sub_2744C` | `0x2744C` | `0x1984C` | `162E:226C` | 已證實：先取得八位元組圖像標頭，再依標頭調整原點及分派；包含複合圖像遞迴 |
| `sub_2744C+0x32` | `0x2747E` | `0x1987E` | `162E:229E` | 已證實：`sub_26A25` 已返回，`SS:BP-0x12` 是標頭，`DX:AX` 指向標頭後的原始內容；尚未分派影像繪製 |
| `sub_2717A` | `0x2717A` | `0x1957A` | `162E:1F9A` | 已證實：統一裁切、壓縮分支與分色面繪製，最後 `retf` |
| `sub_26A25` | `0x26A25` | `0x18E25` | `162E:1845` | 已證實：依資源索引找來源，複製八位元組標頭，再回傳內容起點 |

標頭形狀與既有 TLB 索引一致：高度、Y／X 偏移、四分之一寬度、繪圖方法。
來源掛勾讀取已正規化的目的 Y／X，再依原始碼扣除標頭偏移。
HD 以標頭加原始內容的完整 SHA-256 辨識，保留重複資源 ID 的不同圖格，不以資源 ID 猜圖。
目的位置由來源呼叫取得，畫面像素僅核該位置是否仍完整可見，用於撤除已清除或被遮住的素材。

目前二十二個繪製交易入口與一個影像來源點列在[掛勾資料](../spec/005-render-hooks.json)。
返回以實際呼叫者及 SS:SP 配對，沒有猜固定時間、跳過原版函式或改 CPU 返回值。
只有靜態匯出、建置及資料檢查；新來源點沒有遊戲實測，不宣稱所有動畫、裁切及寫入端都已覆蓋。

## 完整短字串的命令接入

`1212:03A0` 的完整來源沿既有規格；`13C7:0CB6`／IDA linear `0x23826`／檔案偏移
`0x15C26` 是座標正規化後、字形分派前的位置。原字元仍在 `SS:BP+10`，
色彩參數在 `SS:BP+12`。`sub_212FA` 明列原色彩寫入 `DS:0CA16`，
`0x2136D` 的原始呼叫鏈將該值傳入字形函式；不是從畫面辨識英文。

[player_inputs.py](../../tools/player_inputs.py)從正式主表衍生 1,091 筆完整 UI／名稱來源，
另增八個字模；所有既有 2,839 字模與角色 20px 保持。來源保留獨立原文／繁中 TSV，
字墨須在原生八列內，寬度不得超過原字串。既有語境詞框優先，片段不混入完整短句。
[player_text_owner.go](../../tools/player_text_owner.go)在首字形前取得來源及實際座標，
印字返回後核完整逐字位置與可見詞框，再由私有後緩衝產生中文；原版詞框改變時撤除。
只有候選來源與靜態接入，未逐項走訪這 1,091 筆。
